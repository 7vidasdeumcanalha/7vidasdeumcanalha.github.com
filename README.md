# Sete Vidas de um Canalha

Site do Nero para GitHub Pages.

## Publicação
Em Settings → Pages, escolha GitHub Actions. O workflow publica docs.

## Músicas
A página lê o catálogo público da hospedagem original. O painel do artista continua protegido na hospedagem original; salve as alterações lá e recarregue a página pública. catalog.json mantém uma cópia de fallback caso a API esteja indisponível.

## Build
npm install && npm run build
Envie a pasta docs junto com mudanças de código. Não coloque tokens ou senhas no repositório.
